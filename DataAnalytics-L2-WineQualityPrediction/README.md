# Wine Quality Prediction

**Intern:** Satyam Kumar Singh  
**Track:** Data Analytics  
**Task:** Level 2 - Task 2  

## Objective
Train and compare multiple classification models (Random Forest, SGD, SVC) to predict the quality score of wine based on its physicochemical properties.

## What was done
- Loaded dataset and inspected class distribution of quality scores
- Performed EDA (distribution plots + correlation heatmap)
- Discussed class imbalance
- Applied feature engineering (binned quality into categories)
- Used stratified train-test split
- Trained Random Forest, SGD Classifier, and Support Vector Classifier
- Evaluated models using Accuracy, Classification Report, and Confusion Matrix
- Plotted Feature Importance for Random Forest
- Created comparison table of all models
- Concluded the best model for deployment
