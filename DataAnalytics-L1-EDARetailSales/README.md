**Intern:** Satyam Kumar Singh

## Objective
Perform Exploratory Data Analysis on a retail sales dataset to uncover patterns, customer behaviour trends, and actionable business insights.

## Dataset
- File: `retail_sales_dataset.csv`
- Contains: Transaction ID, Date, Customer ID, Gender, Age, Product Category, Quantity, Price per Unit, Total Amount

## Tech Stack
- Python
- pandas
- matplotlib
- seaborn
- Jupyter Notebook

## Key Insights
- Customer base is evenly split by Gender and spread across age groups.
- Age has very low correlation with spending amount.
- Clothing, Electronics and Beauty are the top revenue categories.
- Specific Age Group × Category combinations show high potential for targeted marketing.

## How to Run
1. Open the notebook in Jupyter Notebook or Google Colab
2. Make sure `retail_sales_dataset.csv` is in the same folder
3. Run all cells
