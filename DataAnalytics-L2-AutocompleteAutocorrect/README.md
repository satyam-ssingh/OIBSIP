# Autocomplete and Autocorrect Data Analytics

**Intern:** Satyam Kumar Singh  
**Track:** Data Analytics  
**Task:** Level 2 - Task 5  

## Objective
Analyse the efficiency and accuracy of autocomplete and autocorrect algorithms using NLP techniques.
Implement and compare multiple approaches for text prediction and spelling correction.

## What was done
- Collected and preprocessed a large text corpus
- Applied NLP preprocessing (tokenisation, lowercasing, punctuation & stopword removal)
- Built a frequency-based n-gram model for Autocomplete
- Tested autocomplete on multiple prefixes with top predictions
- Implemented Autocorrect using edit-distance / pyspellchecker
- Tested autocorrect on misspelled words and measured accuracy
- Calculated precision and recall
- Compared different approaches
- Created visualisations (top frequent words + confusion matrix)
- Discussed limitations vs production systems
