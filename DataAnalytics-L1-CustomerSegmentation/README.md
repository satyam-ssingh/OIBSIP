# Customer Segmentation Analysis

**Intern:** Satyam Kumar Singh  
**Track:** Data Analytics  
**Task:** Level 1 - Task 2  

## Objective
Segment an e-commerce company's customer base into distinct groups based on purchasing behaviour using RFM Analysis and K-Means Clustering, and provide targeted marketing recommendations for each segment.

## Dataset
- File: `ecommerce_customer_data_custom_ratios.csv`
- Contains 250,000 transactions from 49,673 unique customers

## Tech Stack
- Python
- pandas
- scikit-learn (KMeans, StandardScaler)
- matplotlib
- seaborn
- Jupyter Notebook

## Key Steps
- Built RFM (Recency, Frequency, Monetary) features
- Applied StandardScaler for normalization
- Used Elbow Method to find optimal number of clusters
- Performed K-Means Clustering
- Profiled each cluster and gave marketing recommendations
