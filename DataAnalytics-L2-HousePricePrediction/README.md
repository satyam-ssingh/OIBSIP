# House Price Prediction using Linear Regression

**Intern:** Satyam Kumar Singh  
**Track:** Data Analytics  
**Task:** Level 2 - Task 1  

## Objective
Build and evaluate a Linear Regression model that predicts house prices based on features such as Area, Bedrooms, Bathrooms, Location, YearBuilt, etc.

## What was done
- Performed EDA (null check, descriptive statistics, target distribution)
- Feature selection and discussion
- Handled missing values and encoded categorical features
- Created Correlation Heatmap
- Train-Test Split (80/20)
- Trained Linear Regression model
- Evaluated using MSE, RMSE, and R² Score
- Plotted Actual vs Predicted prices and Residual plot
- Performed Coefficient analysis
