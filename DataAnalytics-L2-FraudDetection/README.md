# Credit Card Fraud Detection

**Intern:** Satyam Kumar Singh  
**Track:** Data Analytics  
**Task:** Level 2 - Task 3  

## Objective
Build a machine learning pipeline to detect fraudulent financial transactions from a heavily imbalanced dataset, addressing class imbalance as a core challenge.

## What was done
- Analysed class imbalance (percentage of fraudulent transactions)
- Performed EDA on transaction amounts and time patterns
- Explained why Accuracy is a misleading metric for imbalanced fraud data
- Handled class imbalance using SMOTE / class_weight
- Used stratified train-test split
- Trained Logistic Regression + Random Forest / XGBoost
- Evaluated using Precision, Recall, F1-Score, and AUC-ROC
- Discussed which metric matters most in fraud detection (Recall vs Precision)
- Analysed feature importance
- Discussed model scalability for high transaction volume
