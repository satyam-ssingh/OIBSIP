# Sentiment Analysis

**Intern:** Satyam Kumar Singh  
**Track:** Data Analytics  
**Task:** Level 1 - Task 4  

## Objective
Build a machine learning model that classifies the sentiment of text data (positive, negative, or neutral) and provides insights into public opinion or customer feedback.

## What was done
- Loaded dataset and inspected class distribution
- Performed text preprocessing (lowercase, punctuation removal, stopwords, tokenization)
- Used TF-IDF for feature extraction
- Trained Naive Bayes and Logistic Regression / SVM models
- Evaluated models using Accuracy, Precision, Recall, F1-score and Confusion Matrix
- Created WordClouds and performed error analysis
- Concluded the best performing model and real-world applications

- NLTK
- matplotlib / seaborn
