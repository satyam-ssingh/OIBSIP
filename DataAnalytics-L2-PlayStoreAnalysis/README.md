# Google Play Store Analysis

**Intern:** Satyam Kumar Singh  
**Track:** Data Analytics  
**Task:** Level 2 - Task 4  

## Objective
Perform a comprehensive data analysis of the Google Play Store ecosystem — cleaning messy real-world data, 
exploring app categories, analysing ratings and pricing trends, and conducting sentiment analysis on user reviews.

## What was done
- Loaded Play Store apps dataset and user reviews dataset
- Cleaned incorrect data types (Installs, Size, Price)
- Handled null values and removed duplicates
- Performed Category analysis
- Analysed Ratings distribution and average rating by category
- Created Size vs Installs scatter plot
- Performed Pricing analysis (Free vs Paid)
- Conducted Sentiment Analysis on user reviews using TextBlob/VADER
- Analysed sentiment by category
- Provided 3 data-driven insights for app developers

## Tech Stack
- Python
- pandas
- numpy
- matplotlib
- seaborn
- TextBlob / VADER
- Jupyter Notebook
